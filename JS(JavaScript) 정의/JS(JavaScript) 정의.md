## JavaScript 정의
> 자바스크립트는 웹 페이지를 동적, 상호작용하게 만드는 프로그래밍 언어로 HTML/CSS와 통합되어 실행된다. **HTML**은 구조(Structure), **CSS**는 디자인(Style), **JavaScript**는 동작(Behavior)을 담당한다.

### JavaScript 특징
<callout>
	**인터프리터 언어**: 별도의 컴파일 없이 웹 브라우저에서 위에서부터 순차적으로 실행된다.<br>**동적 타이핑**: 변수의 타입이 실행 중 결정된다.<br>**객체 기반 언어**: 자바(Java)와는 별개의 언어로, 프로토타입 기반의 객체지향 언어다.<br>**인터랙티브 웹**: 정적인 HTML 웹페이지에 마우스 움직임, 3D 효과, 데이터 처리 등 동적인 요소를 구현한다.
</callout>

### 동작 방식
<callout>
	HTML 문서 body 하단에 \<script\> 태그로 삽입되거나 .js 파일로 분리한다.<br>브라우저의 JavaScript 엔진(V8, SpiderMonkey 등)이 코드를 해석하여 실행된다.<br>DOM(Document Object Model)을 조작하여 웹 페이지를 동적으로 변경한다.
</callout>
