## VSCode 

> VSCode는 오픈소스 코드 편집기로 효율적으로 코딩할 수 있고, 여러 편의 기능들을 제공하여 대부분의 **언어 개발에 널리 사용되는 도구**다. GitHub와 연동된 파일을 오픈하여 해당 편집기에서 바로 커밋할 수도 있다.

### VSCode 환경변수 설정

> 터미널 해당 폴더 위치에서  `code .` 를 작성하면 바로 VSCode가 열리도록 설정할 수 있다. 

<callout>

	1. 검색창에 **실행** 입력 → 실행창 열기에 **sysdm.cpl **작성해 시스템 속성창 열기 

	2.  고급 → **환경변수 **→ 시스템변수에 내부 클릭 후 p 작성하면 보이는 path 클릭해 **편집** 

	3. 환경 변수 편집 창에서 맨 아래 더블클릭해 내 vscode bin 설치 위치 입력(ex.  C:\\Users\\Administrator\\AppData\\Local\\Programs\\Microsoft VS Code\\bin) 후 **확인**

	4. 이제 폴더 cmd 열고(or 폴더 위치에 바로) code . 입력하면 그 폴더의 VScode가 바로 열린다.

</callout>

### 확장 프로그램&설정 변경

> 관리-확장의 마켓 플레이스에서 여러 확장 프로그램을 다운로드하거나, 설정을 사용자에 맞게 변경할 수 있다.

**한글 패치**

<callout>

	1. **Korean Language Pack for Visual Studio Code**를 설치한다.

	2. VSCode 중앙의 검색창에 **\> Configure Display Language**를** **입력하고 엔터, **한국어 (ko)**를 선택한다.

</callout>

**태그 변경**

<callout>

	**Auto Rename Tag **를 설치해 HTML/XML 코딩 시 같은 짝의 태그명을 함께 변경시켜준다.

	ex) \<div\>\</div\> 에서 시작태그를 \<section\>으로 변경 시 \</div\>도 함께 바뀐다. 

</callout>
