## HTML

### 반응형

> 하나의 웹사이트를 이용하여 PC, 태블릿 PC, 스마트폰 접속 시에 디바이스 기기에 상관없이 화면이 자동으로 호환될 수 있게 변하도록 만드는 웹페이지 방법

**Media Query**

> 반응형 디자인을 생성하기 위한 가장 대표적인 접근법

<callout>

	@ media media-type and(미디어 특성) \{ 스타일 작성\}

	---

	**media-type: **화면(screen), 티비(tv), 프린터(print) 등. 모든 기기면 생략하거나 all 혹은 screen<br><br>**미디어 특성**<br>min-width: 최소값. 요소의 최소 너비를 설정 / 해당 값보다 작아지는 것을 방지<br>max-width: 최대값. 요소의 최대 너비를 설정 / 해당 값보다 커지는 것을 방지<br>orientation: 가로 세로 설정

</callout>
