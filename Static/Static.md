```java
// static: 공유 메모리(클래스 == 메서드)에 변수/메서드 적재
//		   객체 생성과는 무관하게 공간 할당, 클래스명 접근가능
```
### Static 이란
> <br>모든 인스턴스가 공통 값을 공유할 때 사용, 메모리 절약.<br>new를 통해 인스턴스(객체) 생성 없이 클래스 이름으로 호출 가능.<br>Static 영역에 할당되어 프로그램 시작부터 종료될 때까지 메모리에 존재.
