### Method Overriding<br>:메서드 오버라이딩, 함수 재정의
<callout>
	**상속관계를 전제**로 부모 클래스로부터 상속받은 메서드를 자식 클래스에서 **재정의**하는 것.<br>조건<br>1. 메서드 이름, 파라미터 개수나 타입도 동일해야 한다.<br><br>,,,
</callout>
//함수 재정의(메서드 오버라이딩: Method Overriding)<br>*상속관계를 전제*로 상위클래스의 메서드를 하위클래스가 재정의(함수의 Body를 고쳐 사용)하는 것을 허용한 문법<br>메서드의 헤더 부분은 동일하게 두고 본문(\{\})의 로직을 수정할 수 있게 허용함으로서 다양한 형태의 객체가 형성될 수 있도록 유도(다형성의 근거가 될 수 있는 문법 중 하나)<br>상위클래스로부터 동일한 메서드를 물려받더라도 각 하위클래스마다 다른기능구현의 결과물을 만들어낼 수 있다.
```plain text
오버로딩 vs 오버라이딩

//오버로딩
1) 상속 전제 X : 상속에 상관없이 모두 사용 가능
2) 함수 헤더 변경 O : 반환 자료형 고려사항 아님, 함수명 고정, 파라미터 변동
3) 함수 본문 변경 X
4) 목적: 개발 편의성에 중점(함수의 이름은 고정)
        같은 이름의 메서드(함수)를 매개변수의 개수나 타입만 다르게 하여 한 클래스 내에 여러 개 정의

//오버라이딩
1) 상속 전제 O : 상속 관계에서 사용 가능
2) 함수 헤더 변경 X
3) 함수 본문 변경 O
4) 목적: 다형성
```
